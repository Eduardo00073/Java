# Politica de Seguranca

Este repositorio (java-web-app) e um projeto didatico de estudos em Java mantido por Eduardo Junior.

## Reportando um problema

Se encontrar algum problema de seguranca no codigo (por exemplo, exemplos didaticos com Servlets/JSP que nao devem ser usados em producao sem revisao), abra uma issue explicando o contexto.

## Boas praticas recomendadas

- Nao use os exemplos diretamente em producao sem validacao e sanitizacao de entradas.
- Mantenha dependencias do projeto atualizadas.
- Evite expor credenciais em arquivos de configuracao versionados.
